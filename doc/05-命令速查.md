# 命令速查

以下命令以 2026-11-08 当前工作区为准，路径按需替换。

## 1. 环境路径

```bash
# 仓库根
cd /Users/charlie/Downloads/ESP32S3

# Arduino CLI
arduino-cli version

# esptool（中国镜像核心自带）
ESPTOOL="$HOME/Library/Arduino15/packages/esp32/tools/esptool_py/5.3.0-cn/esptool"

# 1.75C 串口
PORT=/dev/cu.usbmodem2101
```

## 3. 设备识别

```bash
"$ESPTOOL" --chip esp32s3 -p "$PORT" chip_id
"$ESPTOOL" --chip esp32s3 -p "$PORT" flash_id
```

预期：ESP32-S3、8 MB PSRAM、32 MB Flash、USB-Serial/JTAG。

## 4. 烧录

### 4.1 完整镜像（首次安装，会清空设置）

```bash
cd ports/175c

"$ESPTOOL" --chip esp32s3 -p "$PORT" -b 921600 \
  write_flash 0x0 \
  dist/MotoNav_175c_v7.12.10-pages.4_panel0_full_0x0.bin
```

### 4.2 仅应用（升级，保留设置）

```bash
"$ESPTOOL" --chip esp32s3 -p "$PORT" -b 921600 \
  write_flash 0x10000 \
  dist/MotoNav_175c_v7.12.10-pages.4_panel0_app_0x10000.bin
```

### 4.3 校验与镜像信息

```bash
"$ESPTOOL" --chip esp32s3 -p "$PORT" verify_flash 0x0 dist/*_full_0x0.bin
"$ESPTOOL" image-info dist/*_full_0x0.bin
```

### 4.4 重要警告

**不要**附加 `--flash_mode qio`、`--flash_freq`、`--flash_size`。镜像头已经是 DIO / 80 MHz / 32 MB；强制 QIO 会导致 `TG0WDT_SYS_RST` 启动循环。


切换 debug/release 签名：

```bash
adb uninstall com.friday.motonav

```

## 8. 签名 SHA1

### 8.1 从 keystore 读取

```bash
# debug
keytool -list -v \
  -keystore android/standard/.local/debug.keystore \
  -storepass android -alias androiddebugkey | grep SHA1

# release（密码从 properties 读取，不直接打印）
PASS=$(grep '^storePassword=' android/standard/keystore/keystore.properties | cut -d= -f2-)
keytool -list -v \
  -keystore android/standard/keystore/release.jks \
  -storepass "$PASS" -alias motonav | grep SHA1
```

### 8.2 从 APK 读取

```bash
APKSIGNER=~/Library/Android/sdk/build-tools/35.0.1/apksigner
$APKSIGNER verify --print-certs app-debug.apk
$APKSIGNER verify --print-certs app-release.apk
```

## 9. 查看 App 数据与日志

```bash
# SharedPreferences 列表
adb shell run-as com.friday.motonav ls shared_prefs

# 和风配置
adb shell run-as com.friday.motonav cat shared_prefs/qweather.xml

# 高德 Key（注意：包含凭据，不要外传）
adb shell run-as com.friday.motonav cat shared_prefs/keys.xml

# 天气日志
adb logcat -s MotoNavWeather

# 清理后重新抓日志
adb logcat -c
adb logcat -s MotoNavWeather
```

## 10. 常见检查

```bash
# 手机是否在线
adb devices -l

# 当前前台页面
adb shell dumpsys window | grep mCurrentFocus

# 已安装包
adb shell pm list packages | grep motonav

# 版本
adb shell dumpsys package com.friday.motonav | grep -E "versionName|versionCode"
```

## 11. 电池探针

```bash
cd ports/175c/diag/battery_probe
arduino-cli compile \
  --fqbn "esp32:esp32:esp32s3:FlashSize=32M,PartitionScheme=app3M_fat9M_16MB,PSRAM=opi,CDCOnBoot=cdc" \
  --output-dir /tmp/battprobe .

"$ESPTOOL" --chip esp32s3 -p "$PORT" -b 921600 \
  write_flash 0x10000 /tmp/battprobe/battery_probe.ino.bin
```

读取 14 秒串口后，恢复 MotoNav：

```bash
"$ESPTOOL" --chip esp32s3 -p "$PORT" -b 921600 \
  write_flash 0x10000 \
  ports/175c/dist/MotoNav_175c_v7.12.10-pages.4_panel0_app_0x10000.bin
```
