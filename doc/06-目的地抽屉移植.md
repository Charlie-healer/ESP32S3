# 目的地抽屉移植（路线 B 第一块）

## 1. 目标

把 StopWatch 的“目的地抽屉”搬到 1.75C 的 175 固件上，同时保持上游 `MotoNav_stopwatch/firmware` 不变。

功能范围：

- 首页底部显示一个星标按钮 `DEST`；
- 轻点星标，向手机请求目的地列表；
- 手机返回收藏地点和历史导航；
- 圆屏显示抽屉，最多 4 项；
- 轻点某一项，手机打开路线规划/搜索目的地页（RoutePlanActivity），确认路线后开始导航。

## 2. 协议

沿用 StopWatch/App 已有协议：

| 方向 | 消息 | 说明 |
|---|---|---|
| 固件 → 手机 | `T,DEST_Q` | 请求目的地列表 |
| 固件 → 手机 | `T,DEST_GO,<idx>` | 选择第 idx 项，手机打开路线规划页 |
| 手机 → 固件 | `#DEST,CLR` | 清空列表 |
| 手机 → 固件 | `#DEST,ADD,<type>,<name>,<addr>` | 添加一项；type 0=收藏，1=历史 |

App 侧 `CallWatcher.onScreenTouch` 已有 `DEST_Q` / `DEST_GO` 分支，`syncDestinations()` 会发送 `#DEST,CLR` 和 `#DEST,ADD...`。1.75 固件原来没有这些处理，这次补齐。

## 3. overlay 文件

所有改动在 `ports/175c/overlay/`，构建时覆盖到 `.build/MotoNav`：

| 文件 | 作用 |
|---|---|
| `overlay/DestHistory.h` | 目的地数据结构、清空/添加 |
| `overlay/DestDrawer.h` | 星标、抽屉绘制、点击处理、`#DEST` 解析 |
| `overlay/src/pages/HomePage.h` | 首页绘制星标/抽屉；抽屉打开时暂停骑手动画 |
| `overlay/src/pages/IncomingCall.h` | 首页轻点事件转给 `destTap()` |
| `overlay/src/protocol/CommandReceiver.h` | `handleText()` 开头调用 `destHandleCommand()` |

上游对应文件不改；`build.py` 在复制 175 源码和 `pin_config.h` 后复制 overlay。

## 4. 交互设计

- 星标位置：`CX=233, Y=408`，半径 16，金色五角星，下方 `DEST`；
- 抽屉：`x=48, y=88, w=370, h=330`，深色圆角面板；
- 最多显示 4 项，每项 54 px 高；
- 收藏项用金色小星，历史项用青色圆点；
- 无数据时显示 `NO DESTINATIONS` / `Open app to sync`；
- 点击抽屉外或星标关闭；
- 点击列表项发送 `T,DEST_GO,<idx>` 并关闭。

## 5. 构建与烧录

```bash
cd ports/175c
python3 build.py --clean --jobs 8
```

新尺寸：

| 项目 | 数值 |
|---|---|
| Sketch | 1,292,463 bytes（41%） |
| 全局变量 | 92,484 bytes（28%） |
| app 镜像 | 1,292,720 bytes |
| full 镜像 | 1,358,256 bytes |

只写应用分区（保留设置）：

```bash
ESPTOOL="$HOME/Library/Arduino15/packages/esp32/tools/esptool_py/5.3.0-cn/esptool"

"$ESPTOOL" --chip esp32s3 -p /dev/cu.usbmodem2101 -b 921600 \
  write_flash 0x10000 \
  ports/175c/dist/MotoNav_175c_v7.12.10-pages.4_panel0_app_0x10000.bin
```

不要加 `--flash_mode qio`；镜像头是 DIO。

## 6. 实机测试步骤

1. 手机解锁，打开 `com.friday.motonav`，确认圆屏已连接；
2. 圆屏停在待机页（骑手画面）；
3. 看底部星标 `DEST`，轻点；
4. 抽屉应打开，手机在后台返回收藏/历史；
5. 轻点一项，手机应打开路线规划/搜索目的地页。

如果抽屉打开但一直 `NO DESTINATIONS`：

- App 里没有收藏地点或导航历史；
- 手机 App 不在后台/被杀；
- `#DEST` 命令没有到达固件，检查 BLE 连接和 App 的“圆屏设置”连接状态。

## 7. 当前限制

- 只显示前 4 项；固件最多存 8 项；
- 名称/地址各截断到 31 个字符；
- 列表名称显示为 App 渲染的 4 位灰度图（中文可读），没有目的地照片/缩略图，地址当前不显示；
- 点选列表项不是直接开始导航，而是打开 App 的 RoutePlanActivity（搜索目的地/路线规划页），由用户确认路线后开始导航；
- 没有滚动；
- 抽屉是简化 UI，不是 StopWatch 的毛玻璃/动画版本；
- 没有震动反馈（1.75C 无马达）；
- 目的地来源依赖 App 的收藏和历史；
- 只在 1.75C overlay 中，上游 175/StopWatch 源码不变。

## 8. 当前状态

- 已编译并烧录 app 分区；
- BLE 广播 `MotoNav-D111`，手机 App 后台 BLE 连接正常；
- 屏幕点击、中文名称图片、滑动方向已实机确认；点选后 App 打开路线规划页。

## 9. 下一块建议

按路线 B 继续，优先级：

1. 圆屏设置页（亮度/旋转/休眠；AXP2101）；
2. 音乐页/手势；
3. 地图主题 VICE/DARK/CLEAN/RADAR；
4. 倾角/G 值（QMI8658 替换 BMI270）；
5. 伴侣模式视觉/触摸（无震动）；
6. 双实体键/马达：1.75C 硬件不支持，保持不支持。
