目标：把 StopWatch 的非硬件限定功能移植到 1.75C；伴侣模式保留视觉/触摸，震动改为声音反馈。

### 7. RTC 离线时钟（ESP32-S3 内部 RTC）

- 微雪 1.75C 资源页没有外置 RTC 芯片的 datasheet；原理图只有 AXP2101 的 `RTCLDO`、`VBAT2 CHG RTC`，以及 ESP32-S3 的 `RTC`/`XTAL_32K` 引脚；
- 结论：1.75C 使用 **ESP32-S3 内部 RTC + 32.768kHz 晶振**，由 AXP2101 的 RTCLDO/VBAT2 持续供电，不是 1.75 上的 PCF85063；
- 手机 `#TIME` 仍然喂 `HomeClock` 和 `settimeofday()`；
- **只调用 `settimeofday()` 不能跨复位保留时间**：ESP32 的系统时间偏移在复位后丢失。曾观察到 `RTC boot time=64`，而更早的 `RTC boot time=1794181625` 实际是 App 在开机后重新同步造成的假象；
- 现在的实现：
  - `HomeClock::receive()` 解析成功的 `#TIME` 后调用 `rtcClockSave()`；
  - `RtcClock.h` 用 `RTC_NOINIT_ATTR` 保存本地 epoch、`esp_clk_rtc_time()` 的微秒基准和 magic；
  - 注意不能用 `RTC_DATA_ATTR`：普通复位时启动代码会重新初始化 `.rtc.data`，`RTC_NOINIT_ATTR` 放在 `.rtc_noinit`，才能跨复位保留；
  - 开机时 `rtcClockInit()` 读取当前 RTC 计数器，计算 `elapsed = (nowUs - baseUs) / 1e6`，恢复 `baseEpoch + elapsed`，再构造 `#TIME` 喂 `HomeClock`；
  - 手机重新连接后继续用新的 `#TIME` 校正基准；
- 实测：
  - 保存基准 `epoch=1794182200`、`rtcUs=238365021`，关掉 App 后复位，`rtcUs=261163426`，恢复 `epoch=1794182222`（补 22 秒）；
  - 再次复位 `rtcUs=460337165`，从基准补 60 秒，随后 App 同步到 `00:00 / 2026-11-09`；
- 限制：完全断开电池/RTCLDO 会丢失基准；下次连接手机自动恢复。

### 9. PWR 短按熄屏 / 亮屏与 CPU 动态调频

来源：`MotoNav-main/firmware/boards/175c` 的 `PwrKeyScreen.h`、`CpuGovern.h`，移植到 `ports/175c/overlay`。

- `PwrKeyScreen.h`：
  - AXP2101 `INTEN2(0x41)` bit3 使能 PKEY 短按；
  - 每 50ms 读 `INTSTS2(0x49)`，bit3 表示短按，写 1 清零；
  - 熄屏：等 `flushDone`，亮度 0，`panel->displayOff()`，`screenDark=true`；
  - 亮屏：先 `cpuBoost()`，`displayOn()`，恢复 `screenBright`，按当前状态重绘配对/来电/音乐/天气/导航/主页；
  - 长按仍由 AXP2101 硬件关机，代码不碰电源开关寄存器；
- `CpuGovern.h`：
  - 熄屏或空闲待机页降到 80MHz；
  - 触摸、拖动、滑页、配对、来电、到达特效、BLE 接收队列非空时保持 240MHz；
  - 当前 Arduino-ESP32 3.3.10 预编译核心没有 PM 框架，所以用 `setCpuFrequencyMhz()` 手动调频；
- 接线位置：
  - `touchPoll()` 每圈先 `pwrKeyPoll(); cpuGovern(); if (screenDark) return;`；
  - `SettingsOverlay` 和 `#b` 命令同步 `screenBright`；
  - 熄屏时 `animateCat()`、`drawWaiting()`、`musicTick()`、`weatherTick()`、`leanTick()`、`fullHomeTick()` 不绘制；
- 已编译通过；实机待机页实测输出 `CPU 80MHz`，临时自检确认 `PWR screen off/on` 重绘路径不崩溃。AXP2101 实体 PWR 按键的最终短按复测仍待完成。

## 设置页使用

- 待机页左下角金色齿轮 `SET`；
- 点击打开面板；
- 点 `BRIGHT` / `ROTATE` / `THEME` / `SLEEP` 行循环；
- 点 `HOME` 行在 `RIDER` / `VICE` 待机页之间切换；
- 点 `COMPANION` 进入伴侣模式，右上角 X 返回；
- 点面板外关闭。

如果齿轮点不开，说明 1.75C 的触摸 X 镜像方向和 1.75 不同；需要把 `TOUCH_FLIP_X` 改为 0，或把齿轮移到对称位置。
