## 当前状态速览

- 1.75C 已完成固件烧录、启动、BLE 广播和手机 App 连接验证。
- App 显示 `MotoNav-D111 已连接 / 已配对验证`，圆屏电量曾显示 100%。
- 屏幕显示、触摸、导航数据、音频和长时间稳定性尚未逐项实机确认，以现场实测为准。
- 电池电压实测 4.207 V、处于 CV 充电阶段；AXP2101 电量计曾从 7% 逐步上升到 100%，属于电量计重新学习，不是电池损坏。
- App 的天气链路已补回，但还需要在和风控制台申请 API Host 与 API Key 才能显示天气。
- 离线时钟已实现：手机 `#TIME` 的基准存 `RTC_NOINIT_ATTR`，重启后按 ESP32-S3 RTC 计数补经过时间；无 App 同步的复位实测可恢复。
- 倾角/G 页面已改用 SensorLib 新 QMI8658 驱动，启动自检 `LEAN: QMI8658 ready`，待触摸实机确认。
- 待机主页支持两种皮肤：默认 RIDER（当前骑手主页），设置页 `HOME` 可切换到 VICE 完整待机页；两套共用抽屉、设置、倾角和 RTC/HomeClock。

## 重要提醒

- 不要把 keystore、keystore 密码、高德 Key、和风 Key 写入文档或提交到公开仓库。
- `MotoNav_stopwatch/` 是第三方参考代码：项目自有部分为非商业许可，`AvatarEngine` 为 AGPL-3.0。公开分发时需保留 `LICENSE.md`、`licenses/LICENSE-AGPL-3.0.txt` 和来源说明，禁止未经许可的商业使用。
- 烧录完整镜像会清空设备设置；烧录前先确认不需要保留原固件或数据。
- 1.75C 的 32 MB Flash 目前只使用前 16 MB 分区，后 16 MB 闲置。
